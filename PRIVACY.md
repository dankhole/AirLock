# Privacy Policy

**Airlock** does not collect or transmit personal data.

Your tracked site list, settings, content-control preferences and per-site daily usage totals are stored locally on your device using the browser's extension storage APIs. Daily usage records focused time only on sites you add to Airlock, resets at local midnight, and continues whether or not a daily limit or the main Restrictions switch is enabled. Timer session data is stored in session storage and is cleared when the browser closes.

Content controls inspect the current page's URL and elements locally to identify selected features such as Reels, Shorts or Stories. Navigation notifications are used to refresh these controls; Airlock does not save a browsing-history log, page contents, message text or a record of hidden posts. It does not add monitoring for a site merely because its content controls are enabled.

Airlock sends no settings, usage totals or page contents to any server or external service and includes no analytics or telemetry. Optional redirects navigate your browser to another page on the same website, which makes the normal requests associated with visiting that page. Hiding elements does not prevent the website itself from loading media or collecting data under its own policies.

## Permissions

| Permission | Why |
|---|---|
| `storage` | Save settings, daily usage totals, and timer state locally on your device |
| `activeTab` | Read the current tab's URL when you open the popup, so the "Track this site" button can work |
| `alarms` | Reset waits at midnight and apply scheduled lock and cooldown boundaries |
| `webNavigation` | Refresh supported-site controls after top-frame page and History API navigation |
| Site access | Display Airlock's overlay on tracked sites and apply enabled content controls on YouTube, Instagram and Facebook |
