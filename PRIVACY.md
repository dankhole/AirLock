# Privacy Policy

**Airlock** does not collect or transmit personal data.

All data (including your tracked site list, settings, and per-site daily usage totals) is stored locally on your device using the browser's built-in extension storage APIs. Daily usage records only focused time on sites you add to Airlock, resets at local midnight, and continues whether or not a daily limit or the main Airlock toggle is enabled. Timer session data is stored in session storage and is automatically cleared when the browser closes.

No data is sent to any server, third party, or external service. The extension makes no network requests and includes no external analytics or telemetry.

## Permissions

| Permission | Why |
|---|---|
| `storage` | Save settings, daily usage totals, and timer state locally on your device |
| `activeTab` | Read the current tab's URL when you open the popup, so the "Track this site" button can work |
| `alarms` | Reset waits at midnight and apply scheduled lock, cooldown, and guarded-setting boundaries |
